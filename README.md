# Natural_Language_to_SQL_Agent
An AI-powered Natural Language to SQL Agent using Gemini AI, MySQL and Streamlit.

## 🗄️ Database

This project uses **MySQL** as its backend database.

The application works with the following four tables:

* `student`
* `bridge`
* `chess`
* `music`

The database table structure is provided in [`database/schema.sql`](database/schema.sql).

Database credentials and API keys are **not included in this repository**. They are managed using environment variables / Streamlit Secrets.
